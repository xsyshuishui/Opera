## 一、核心结论：agent 确实复现了搜索发现的反直觉行为，且比搜索更激进

L5hQ 的质疑是：*VLM 先验偏好直觉选择，GRPO 从这个有偏先验出发探索，学到的 planner 真的能复现搜索发现的超纲/重复行为吗？* 数字给出了明确答案：

| 行为 | §3 穷举搜索中高分计划 | **训练后 agent 的实际计划** | 判定 |
|:---|:---:|:---:|:---|
| 含 ≥1 个**超纲**工具 | 60.0% | **97.1%** (1398/1440) | ✅ 复现，且远超 |
| 含**重复**工具（同功能类） | 77.6% | **90.5%** (1303/1440) | ✅ 复现，且超出 |
| 含重复工具（**完全同一工具**） | — | 1.7% (24/1440) | ⚠️ 见下 |

**超纲调用占全部工具调用的 52.6%**（2686/5106）——与上一轮 rebuttal 文档 `Rebuttal_Q2_Failure_Case_Analysis.md` 中独立算出的 52.6% **完全一致**，两次独立统计交叉验证。

### 最常被超纲调用的工具
| 工具 | 超纲次数 | 占全部图像 |
|:---|---:|---:|
| `restormer.deblur.motion.v1` | 929 | 64.5% |
| `restormer.deblur.defocus-single.v1` | 876 | 60.8% |
| `xrestormer.sr.real.v1` | 395 | 27.4% |
| `xrestormer.deblur.motion.v1` | 192 | 13.3% |
| `xrestormer.dehaze.haze.v1` | 162 | 11.2% |

与上一轮 rebuttal 的工具影响分析结合，形成一条**完整且自洽的论证链**：agent 大量超纲调用的正是 `deblur` 系（误用时 **+1.40 dB / +0.16 dB**，无害甚至有益），而对有害工具（`denoise.sigma50` 误用 **−3.98 dB**）的误用率仅 7.3%。**agent 隐式学到了工具误用的代价不对称性** —— 这是回应 AC-Q3 最有力的材料。

### ⚠️ 一个需要修正表述的细节
论文 §5.3 称「deblurring 被反复调用 97.3%」。实测显示：**同功能类**重复 90.5%，但**完全相同工具**重复仅 1.7%。也就是说，agent 的「重复」几乎全部是 `defocus-blur + motion-blur` 这类**同族不同工具的组合**（1302/1303 集中在 `restormer.deblur` 族），而非真正把同一个工具跑两遍。

**建议**：rebuttal 中把「repetition」精确表述为「同族工具的级联」，避免审稿人按字面理解为「同一工具重复」后发现对不上。诚实的精确化比含糊的强表述更安全。

## 四、失败分析（回应 oqzW-Limitations、AC 对定量失败分析的要求）

**总体：29.3%（422/1440）的图像 PSNR < 20 dB。**

| 类别 | 失败率 |
|:---|---:|
| Group C/dark+defocus blur+jpeg | **87.0%** |
| Group A/motion blur+dark | **82.5%** |
| Group A/dark+noise | **76.2%** |
| Group B/rain+dark | **76.0%** |
| Group C/haze+motion blur+low res | 30.0% |
| Group B/haze+noise | 21.0% |
| Group A/defocus blur+haze | 20.0% |
| Group C/motion blur+defocus blur+noise | 18.0% |

**失败高度集中在含 `dark` 的四个类别（76–87%），其余类别均 ≤ 30%。** 根因很清楚：**工具池里根本没有针对低照度的工具**。实际被调用过的 9 个工具覆盖 deblur / denoise / derain / dehaze / SR，**没有任何 brightening 或 low-light 工具**。agent 面对 `dark` 时无工具可选，只能调用其他工具，PSNR 自然崩塌。

这条与 uawM-W1（「固定 8 类退化头、无 unknown 选项，OOD 行为未定义」）**直接呼应**——不是分类头识别不出 dark，而是**识别出来了也无工具可用**。这个区分对 rebuttal 很重要，也是一个可以坦率承认并转化为 Limitations 的点。

## 五、🔴 重要发现：论文 Table 1 依赖一个正文未描述的后处理

核对指标时发现的事实链：

| 来源 | Group A | Group B | Group C |
|:---|:---:|:---:|:---:|
| `Results/inference_agent_20260327_182645`（本批） | 23.27 | 22.75 | 21.93 |
| 上一轮 rebuttal 文档中的「Ours」 | 23.27 | 22.75 | 21.93 |
| 上一轮 rebuttal 文档中的「Ours + brightening」 | **24.81** | **24.63** | **23.04** |
| **论文 Table 1 的 Ours (Full)** | **24.81** | **24.63** | **23.04** |

四行数据、三个组、六项指标（PSNR/SSIM/LPIPS/MANIQA/CLIPIQA/MUSIQ）**逐一精确匹配**。结论明确：

> **论文 Table 1 报告的 Ours (Full) = 本批 agent 计划 + 一个直方图均衡（histogram equalization）后处理。**

从 `brightening_test_*/per_image_results.csv` 可见，该实验的三个配置为 `baseline` / `prepend_histogram_equalization` / `append_histogram_equalization`，且**三者的 pipeline 字段完全相同** —— 即 brightening 是外挂在计划前/后的图像处理步骤，**不是工具池中由 agent 调度的工具**。

### 对 rebuttal 的影响

- ✅ **好消息**：agent 的 plan 在加 brightening 前后**没有变化**，所以本文档全部行为统计（超纲率、重复率、多样性、链长）**对论文版本同样成立**，无需重算。
- 🔴 **风险**：论文正文（§4、§5.1、Appendix C）未描述这一后处理。若审稿人索要复现细节或代码，这会成为一个难以解释的缺口。考虑到 AC 的核心疑虑本就是**归因**（「增益到底来自哪里」），此处尤其敏感。
- **建议**：在 rebuttal 中**主动、简短地澄清**该后处理及其贡献（Overall +1.52 dB），并在 camera-ready 补入正文。主动说明远好于被追问——上一轮 rebuttal 已有完整的消融表格（`Rebuttal_Brightening_Tool.md`）可直接引用，材料是现成的。

## 六、可立即写入 rebuttal 的结论

1. **AC-Q3 前半 / L5hQ-Q1 已可作答**：agent 复现了搜索发现的反直觉行为，超纲 97.1%（搜索 60.0%）、同族重复 90.5%（搜索 77.6%），且超纲集中于误用无害的 deblur 系、罕用有害的 denoise 系 —— 说明它学到的是**代价不对称性**，而非盲目堆砌工具。
2. **oqzW-Q5 已可作答**：平均 3.55 次调用、4 步达峰、无误差累积、失败率 29.3% 且高度集中于缺工具的 `dark` 类。
3. **仍需 GPU 的部分**：顺序置换（E3b）与工具移除（E3c）——这两项才能把「相关」升级为「因果」，是 AC-Q3 后半的正面回答。数据包到位后即可启动。
